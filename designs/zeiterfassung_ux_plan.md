# Zeiterfassung UX Flow Plan (EIS-48)

## Overview
Design comprehensive UX flows for the Zeiterfassung feature across Mobile, Web (Portal), and Admin Dashboard.

## Accessibility Principles
- **WCAG POUR:** Perceivable, Operable, Understandable, Robust.
- **Senior Friendly:** High contrast, large touch targets, simple, linear flows, clear feedback, reduced cognitive load.

## Mobile App Flow (Employee)
1. **Appointment List (Home):**
    - View active/upcoming tasks.
    - Clear "Start" button for the current task.
2. **Start Timer:**
    - Visual feedback that the timer is running.
    - Current duration displayed prominently.
3. **Stop Timer:**
    - "Stop/Finish" button.
    - Confirmation step (to prevent accidental stops).
4. **Report Generation:**
    - Simple form for task report (text or predefined tags).
    - Summary of time logged.
5. **Customer Signature:**
    - Sign-pad area (large).
    - "Confirm & Submit" button.
6. **PDF/Email:**
    - Automatic generation (or confirmation step for user).

## Web Portal Flow (Employee)
1. **Login:** Simple, secure access.
2. **Appointment Planner:**
    - Calendar view.
    - Map-integrated view (for task location/route planning).

## Admin Dashboard Flow (Admin)
1. **Monitoring Overview:** Real-time overview of active timers.
2. **Audit Trail:** Historical view of completed tasks, signatures, and time logs.
3. **Employee Management:** Manage employee profiles, schedules, and permissions.
