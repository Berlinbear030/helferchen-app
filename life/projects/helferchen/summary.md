# Project Helferchen
Helferchen is a dedicated service company assisting seniors with everyday technical and household challenges. 
Focus: Technical assistance (TV installation, smartphone setup) and household tasks (window cleaning).
Pricing: 20 EUR (first 15m), 15 EUR (subsequent 15m).

## Current Status
- Pilot distribution in Steglitz-Zehlendorf active (350/500 flyers distributed).
- 6/8 strategic partnerships secured.
- Phase 2 implementation started (Backend, Website, UI Design).
